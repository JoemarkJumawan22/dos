# Joemark S. Jumawan — Portfolio

Neon-cyber portfolio site with enhanced animations.

## Pages
- `index.html` — Home / Hero
- `about.html` — About + timeline
- `work.html` — Projects grid
- `contact.html` — Contact form
- `transmissions.html` — Local inbox for form messages
- `shopzilla.html`, `registrack.html`, `future-builds.html` — Project detail pages

## Assets
Place your images in the `images/` folder:
- `siDos_Suit.png` (profile)
- `bg-shopzilla.png`, `shopzilla.png`
- `R-Background.png`, `RegisTrack.png`
- `background.png`, `logo.png`

## Features
- Custom neon cursor + follower
- Page transition overlay
- Scroll-triggered reveals (fade / slide / scale)
- Staggered skill chips, project cards, contact cards
- 3D tilt on project cards
- Typewriter on home
- Glitch + gradient text effects
- Floating orbs + animated grid
- Contact form → localStorage → Transmissions inbox
- Responsive + reduced-motion support

Open `index.html` in a browser to view.
